# Contributing

The rules for contributors live next to the code:

- [CONTRIBUTING.md](https://github.com/vymalo/another-agentic-system/blob/main/CONTRIBUTING.md): claim an issue, build, test, open a pull request.
- [SECURITY.md](https://github.com/vymalo/another-agentic-system/blob/main/SECURITY.md): report a vulnerability privately.
- [ROADMAP.md](https://github.com/vymalo/another-agentic-system/blob/main/ROADMAP.md): the milestones.

Decisions are ADRs in [docs/decisions](decisions/); a change of mind is a new ADR or a dated amendment.
